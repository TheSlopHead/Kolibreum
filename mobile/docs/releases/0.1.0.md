# mut · Android 0.1.0

Первая тестовая Android-версия mut: локальная зашифрованная библиотека и читалка на основе мобильных макетов Paper.

- Создание и блокировка архива, пароль и локальный recovery code.
- Импорт книг, поиск, полки, редактирование метаданных и экспорт оригинала.
- Удаление книг из текущей библиотеки с подтверждением.
- EPUB, FB2 и PDF: постраничное чтение и вертикальная лента, номер страницы и процент, закладки и сохранение места.
- Настройки текста для EPUB/FB2; масштабирование PDF.
- Ленивое отображение страниц и сохранение позиции без перестроения всей библиотеки.
- Зашифрованные backup и восстановление с проверкой содержимого.

APK `mut-0.1.0-android-arm64.apk` предназначен для Android 8.0+ (API 26), архитектура arm64-v8a. Контрольная сумма находится в `SHA256SUMS`.

Это pre-release. EPUB/FB2 пока отображаются как упрощённый текст без изображений и CSS книги; предел импортируемого файла — 32 МиБ. Удаление не изменяет исходный файл и прежние backup, недостижимый ciphertext пока сохраняется. Число страниц EPUB/FB2 зависит от экрана и настроек текста. Криптографический прототип ещё не прошёл независимый аудит.

APK использует постоянную release-подпись. При переходе с прежнего APK, подписанного debug-ключом, Android может потребовать удаление старого приложения. **Сначала создайте зашифрованный backup через приложение и убедитесь, что знаете его пароль или recovery code**: удаление приложения стирает его локальную библиотеку. Следующие версии с тем же applicationId и release-ключом устанавливаются как обновление.
