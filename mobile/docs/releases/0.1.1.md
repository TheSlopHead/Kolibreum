# mut · Android 0.1.1

Обновление мобильной библиотеки: обложки из файлов и исправление SEC-02 с переходом на формат архива v2.

- Обложки EPUB 2/3 и FB2 извлекаются при импорте; для PDF используется превью первой страницы. Если обложки нет, она повреждена или её формат не поддерживается, остаётся текстовая карточка.
- Миниатюры шифруются отдельно от исходников, входят в backup/restore и проверяются перед сохранением и восстановлением копии. Проверка старых книг выполняется при первом показе. Внешние изображения не скачиваются.
- Обложки отображаются в библиотеке, поиске, полках, карточке книги и панели продолжения чтения. При блокировке их буферы и изображения освобождаются; глобальный Flutter ImageCache для обложек не используется.
- Исправлен SEC-02 в мобильном формате v2: ключи HKDF и AEAD AAD разделены для объектов и каталога. Ciphertext импортированного файла нельзя использовать вместо снимка каталога.
- Старые мобильные архивы v1 автоматически мигрируют после открытия паролем или recovery code. Оригиналы, обложки, UUID, метаданные, полки, настройки, прогресс и закладки сохраняются. Зашифрованный источник остаётся в `vault.v1`.
- Старые v1 backup проверяются и мигрируют в staging до замены действующей библиотеки. Повреждение объектов/обложек прерывает миграцию без изменения источника; восстановление после прерванного переноса учитывает маркер миграции.
- Добавлены регрессии SEC-02, проверки миграции и независимые Go-векторы мобильного v2, включая чтение Dart ciphertext Go-примитивами. В README добавлена галерея мобильных экранов.

Версия Flutter — `0.1.1+3`. APK `mut-0.1.1-android-arm64.apk` предназначен для Android 8.0+ (API 26), архитектура arm64-v8a. Контрольная сумма подготовленного APK находится в `SHA256SUMS`.

## Обновление с 0.1.0

Перед обновлением сохраните зашифрованный backup и проверьте пароль/recovery code. APK должен быть подписан **тем же релизным ключом**, что 0.1.0: он устанавливается поверх прежней версии без удаления приложения. Миграция начинается при первом открытии архива и требует свободного места для второй зашифрованной копии; `vault.v1` остаётся на устройстве. Приложение 0.1.0 не открывает активный архив v2.

Для установки поверх прежнего debug APK может потребоваться удаление приложения; оно стирает локальную библиотеку. Сначала сохраните backup вне приложения. После установки можно восстановить старую мобильную v1-копию: она будет проверена и мигрирована.

## Границы тестовой версии

Это pre-release; криптографический прототип не прошёл независимый аудит. SEC-02 исправлена для активного мобильного v2; исторические v1-копии не становятся защищёнными задним числом. Миграция не доказывает, что v1-каталог не был подменён до открытия. Возврат к старым согласованным header/HEAD/ciphertext не предотвращается этим исправлением.

Go-ядро не изменялось: проверки через независимые Go-примитивы не объявляют полную совместимость архива с Go-приложением. EPUB/FB2 читаются как упрощённый текст без CSS и иллюстраций внутри страницы. Обложки поддерживают PNG/JPEG; SVG и анимация не поддерживаются. Предел исходного файла — 32 МиБ. Реальные SAF-переходы и миграция на Android требуют проверки на устройстве.
