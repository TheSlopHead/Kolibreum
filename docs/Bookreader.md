# mut — личная библиотека

Название проекта: **mut**. В описаниях приложения допустимо **mut reader**; основное написание — строчными буквами. Статус: проектное предложение, 26 сентября 2026 года.

## Идея в одном предложении

Красивое и быстрое Linux-приложение для личной библиотеки: книги зашифрованы на компьютере, их удобно читать, архивировать, проверять и восстанавливать; отдельные материалы можно передать конкретному человеку.

**Короткое обещание для сайта:** «Твоя библиотека остаётся твоей». Под ним всегда уточнение: «Хранится локально в зашифрованном архиве. Резервные копии и передача — только по твоей команде».

## Зафиксированные решения

- Linux desktop сначала; одна локальная библиотека и один пользователь в v1.
- Go для приложения и ядра; Wails v2 (стабильная ветка), Svelte + TypeScript + Vite для интерфейса. C сейчас не требуется.
- Импорт принимает файл **любого формата**: сохранить, зашифровать, забэкапить и восстановить можно всё. Встроенное чтение (навигация, размер текста где возможно, закладка, продолжение) поддерживается только для PDF, EPUB, FB2 в v1; остальные форматы хранятся как обычный объект с карточкой «нет встроенного чтения» и кнопкой «открыть/экспортировать во внешнюю программу». Список форматов для будущих адаптеров чтения — в ROADMAP.md.
- Локальное шифрование, переносимый экспорт и проверяемое восстановление — бесплатное ядро.
- Никакого аккаунта, сервера, телеметрии, фонового сканирования сети или обязательного AI в v1.
- Обмен выбранным объектом по ключу и локальный AI — отдельные этапы после проверки основного продукта.
- Исходники клиента публикуются по открытой лицензии; конкретный текст лицензии и лицензии зависимостей проверить до первого публичного релиза. Предварительный выбор — MPL-2.0; спецификация формата и тестовые векторы открыты.
- Проект делается прежде всего для себя и небольшого круга друзей, и как демонстрация инженерных решений (портфолио). Погоня за размером рынка и монетизацией — не цель v1; см. упрощённые разделы валидации и бизнес-модели в PRODUCT.md.

## Чего нет и не будет

Это не спецификация DRM, обхода ограничений издателей, публичного каталога чужих книг, анонимности или защиты от вредоносной программы на уже разблокированном ПК. Обмен файлами через капсулу — только для собственных произведений, общественного достояния и материалов с явным разрешением на распространение. Это **постоянный принцип продукта**, а не временное ограничение до правовой оценки рынка: он не пересматривается ростом спроса на распространение материалов без такого разрешения, в том числе книг, запрещённых государством, но защищённых чужими правами. Юридические правила для рынков запуска проверить отдельно.
